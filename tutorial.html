📌 핵심 요약 (Quick 3 Steps)

STEP 01
GitHub Issue 클릭 작성
상단 `Issues` 탭 ➔ `New Issue` 클릭 후 원하는 요구사항을 한글로 카톡처럼 편하게 작성합니다.
STEP 02
Feedback.md 연필 클릭
`Wiki/Feedback.md` 파일에서 연필(Edit) 버튼을 누르고 요구사항을 적은 뒤 저장(Commit)합니다.
STEP 03
안그래 16-Agent 자동 처리
안그래 군단이 실시간 수집(`INGEST`)하여 작업을 완료하고 보고서 댓글을 남겨드립니다.
