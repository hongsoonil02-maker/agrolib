## 📢 하달 지시문 (Executive Command)

전체 16개 에이전트는 즉시 **Agrolib Central Obsidian Vault OS + GitHub Collaboration Protocol** 헌장과 규격을 행동 지침으로 수동(Ingest) 및 자동 이행하라.

### 1. GitHub 협업 시스템 동기화 (`INGEST` & `SAVE`)
- 임직원이 GitHub Issue, Pull Request (PR), Issue Comment에 지시사항이나 피드백을 등록하면 Agent 15 (Feedback Ingestor)와 Orchestrator가 `INGEST`하여 최우선 목표로 변환한다.
- 5-Filter 검증을 마친 결과물은 안그래(Orchestrator)가 GitHub 레포지토리에 자동 Commit & Push / PR을 발송(`SAVE`)하여 원격 레포와 `agrolib` 볼트를 완전 파이프라인 동기화한다.

### 2. 관제 범위 전사 확장 및 중앙 대시보드 고정
- 퀀트 자동매매뿐만 아니라 **전사 12개 프로젝트(`100_bagger_saas`, `100_bagger_backend`, `quant_system`, 봇 4종, 랜딩 4종, 스마트축산)** 전체의 지식, 코드, 이슈, PR을 동시 관제한다.
- **[Central Control Tower Dashboard]**: `file:///c:/Users/master/agrolib/index.html` 대시보드를 전사 중앙 관제 탑으로 수용하여 매 세션 복원 시 최우선 지식 기준선으로 삼는다.

### 3. 5-Filter System 의무 이행
- 모든 작업 결과 및 결론을 `Agrolib/Wiki` 및 GitHub에 저장(`SAVE`)하기 전 반드시 5-Filter (재사용성, 가독성, 근거 명확성, 결론 요약성, 불변성 검증)를 통과시켜라.

### 4. 제어어 영문 고정
- 시스템 및 파이프라인 트리거 시 `EXECUTE_TOURNAMENT`, `INGEST`, `LINT`, `SAVE`, `PURGE_CONTEXT` 영문 키워드만을 엄격히 사용하라.
