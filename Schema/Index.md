## 🛡️ 5-Filter System (지식 저장 및 맥락 오염 방지)

12개 전사 프로젝트 지식을 `/Wiki` 및 GitHub에 퍼블리싱(`SAVE`)하기 전 적용하는 5단계 검증 필터입니다.

| Filter # | 검증 기준 (Validation Gate) | 설명 |
|---|---|---|
| **Filter 1** | **재사용성 (Reusability)** | 이 정보/코드가 퀀트, SaaS, 랜딩 개발 시 재사용 가능한가? |
| **Filter 2** | **가독성 (Readability)** | 임직원 또는 다른 에이전트가 쉽게 읽고 활용할 수 있는가? |
| **Filter 3** | **근거 명확성 (Traceability)** | 프로젝트명, 백테스트 조건, 서버 사양, API 규격이 명시되었는가? |
| **Filter 4** | **결론 요약성 (Conciseness)** | 노이즈 데이터가 축소되고 핵심 인사이트가 압축되었는가? |
| **Filter 5** | **불변성 검증 (Immutability)** | `/Raw` 원본 데이터와 100% 일치하며 훼손되지 않았는가? |
